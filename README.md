# extraDork

Python tool for generating Google Dork search queries.

## Installation

```bash
git clone https://github.com/evezme/extradork.git
cd extradork
python3 main.py
```

## Usage

Enter the desired parameters. Leave a field blank to skip it.

The program will generate a Google Dork query from the provided parameters.

## Requirements

* Python 3.x
